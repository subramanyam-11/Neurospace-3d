# NeuroScope 3D — Frontend Client

React + Vite + Three.js interactive 3D medical visualizer.

## Setup & Running
```bash
cd "/Users/subramanyam/Aura 1/frontend"
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

URL: `http://localhost:5173`
Backend proxy / target: `http://localhost:8000`
